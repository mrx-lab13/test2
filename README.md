# KROSS×OVER 公式サイト リニューアル（実装版 v2 / デザインモック準拠）

支給いただいたデザインモックのレイアウト・カード構成・情報の見せ方に合わせて全面的に組み直した版です。
ビルドツール不要の静的HTML。ZIPを解凍してそのまま設置できます。

## ファイル構成

```
index.html        トップページ（HERO / 直近の試合予定 / チャンピオン / スポンサー / コンテンツ）
schedule.html     試合日程
news.html         ニュース
results.html      試合結果（2018〜2026 アーカイブ 53件）
rules.html        KROSS×OVER公式ルール及び出場エントリー
champions.html    現王者20階級 + 歴代王者一覧
contact.html      お問い合わせ
style.css / script.js
images/1.jpg〜6.jpg      使用中（ロゴ / HERO背景 / 大会カード / 王者カード）
images/mock/7〜12.jpg    未使用（指示書§8のスポンサーモック。公開サイトでは使用しない）
```

## モックからの意図的な変更点（指示書§3・§22に準拠）

| モック | 実装 | 理由 |
|---|---|---|
| ナビ「選手 / ランキング / フォト・動画」 | 未実装 | 既存サイトの主要ナビに存在しないため（§3） |
| 「新規会員登録 / ログイン」ボタン | 「TICKET（赤）/ お問い合わせはこちら」 | 会員機能は既存サイトに無いため、同じ位置に既存導線を配置 |
| 大会名 RE:IGNITION 等の架空タイトル | 実在の大会名 | 架空の大会名は使用不可（§0） |
| 王者「山田 太郎」等の架空名 | 公式サイト掲載の実名・階級・代数 | 同上 |
| フッターの電話番号 03-1234-5678 / info@ | 公式問い合わせフォームへのリンク | 架空の連絡先は掲載不可（§13） |
| スポンサー6社（VENUM等のモック画像） | 公式サイト掲載の実スポンサー9社 + 実リンク | モック素材は公開サイトで使用不可（§8） |
| プライバシーポリシー / 利用規約 | 未実装 | 既存サイトに該当ページが無いため |

レイアウト・配色・カード構成・アイコン付きコンテンツカード・フッター5カラムなど、
見た目の方向性はモックのまま踏襲しています。

## 本番公開前の差し替え

1. **ロゴ**（`images/1.jpg`）→ 背景透過のPNG/SVGへ。現在は黒背景JPGを `mix-blend-mode:screen` で抜いています
2. **大会カード画像**（3〜5.jpg）→ 各大会の正式ポスターへ
3. **王者カード画像**（6.jpg）→ 各王者の正式写真へ（現在は全枚共通のモック）
4. **スポンサーロゴ** → 現在は krossover.jp の既存画像を直接参照。公開時は自ドメインへ移設し `src` を差し替え。
   既存画像は白背景・縦長バナー・広告画像などサイズがバラバラなため、横長・背景透過に統一した素材をいただけると見栄えが揃います
5. **記事本文の移行** → ニュース / 試合結果の本文・試合カード・勝敗・KO/TKO時間・画像は既存WordPress／Ameba側に残したままリンク中
6. **公式ルールPDF** → ファイル移行後、各項目から直リンクへ

## 実装メモ

- 配色・角丸・枠線は指示書§16のトークン（`style.css` 冒頭の `:root`）
- PC 1200px以上でグローバルナビ全項目表示、それ未満はハンバーガー（ナビ名称を短縮しないため）
- EVENT 3カラム / CHAMPION・SPONSOR 6カラム / SP時 CHAMPION 2カラム（§17準拠）
- アニメーションはスクロール時のフェードのみ。`prefers-reduced-motion` で無効化
- title / description / canonical / OGP / alt を全ページ設定済み。URL変更時は301リダイレクトが必要です
